# Task-01: Responsive Landing Page

A responsive and interactive landing page developed as part of my **ProDigy Infotech Web Development Internship**.

### 🚀 Features

* 📱 Fully responsive design for different screen sizes
* 🧭 Fixed navigation menu visible across the page
* 🎨 Navigation menu changes style/color while scrolling
* 🖱️ Interactive hover effects on navigation items
* ⚡ JavaScript-based scrolling interactions
* 🎯 Clean and modern UI design
* 🌐 Built using HTML, CSS, and JavaScript

### 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

### 📌 Task Objective

The objective of this task was to create an interactive navigation menu that remains fixed while navigating through the page and dynamically changes its appearance based on scrolling and user interaction.

This project helped me strengthen my understanding of **responsive web design, CSS styling, DOM manipulation, JavaScript events, and interactive UI development**.
